# 修复后量化交易平台底层逻辑说明书 v2.0

> **写给产品经理的大白话版本** — 不涉及代码细节，只解释系统如何工作

---

## 一、系统整体交易流程

### 一句话概括

系统每4小时检查一次市场，判断当前是牛市/震荡市/熊市，如果指标同时发出信号，就开仓买入（或做空卖出），然后等止盈或止损触发后平仓。

### 完整流程（通俗版）

```
每4小时一根K线（蜡烛图），系统做以下事情：

1. 断路器检查
   → 如果之前连续亏了3笔，锁仓2天不交易（强制冷静期）

2. 检查已持仓的止盈止损
   → 先看价格是否达到了止盈价或止损价
   → 如果同一根K线两边都可能触发，保守原则：取止损
   → 如果启用移动止损，盈利够多后止损会自动上移

3. 选币开仓
   → 扫描所有币种（ETH/BTC/SOL）的信号
   → 选评分最高的那个币
   → 判断当前市场是牛/震/熊 → 决定用多少仓位
   → 开仓买入

4. 资金费率结算
   → 每8小时结算一次（模拟真实交易所）
   → 做多付钱，做空收钱

5. 权益记录
   → 记下当前账户总价值

→ 然后看下一根K线，重复
```

## 二、牛熊/震荡判断逻辑

### 三因子打分

系统用三个指标来综合判断市场状态，每个指标给出一个分数（-1到+1），然后加权求和：

| 因子 | 权重 | 简单解释 |
|------|------|---------|
| EMA趋势 | 40% | 价格均线的方向。往上走=看多，往下走=看空 |
| ADX强度 | 35% | 趋势是否可靠。趋势强+方向对=高分 |
| 资金费率 | 25% | 大家都在做多吗？太多人做多=可能要跌 |

### 计算公式（大白话版）

```
最终分数 = EMA分数 × 0.40 + ADX分数 × 0.35 + 资金费率分数 × 0.25

如果最终分数 > +0.30  →  牛市 🐂
如果最终分数 < -0.30  →  熊市 🐻
在 -0.30 ~ +0.30之间  →  震荡市 ↔️
```

### 震荡市场是怎么产生的？

震荡不是系统主动判断出来的"震荡"。

震荡是三种指标的结果相互抵消后的**默认状态**。

比如：
- EMA显示略偏多（+0.2），ADX显示方向不明（-0.1），资金费率中性（0）
- 总分 = 0.2×0.4 + (-0.1)×0.35 + 0×0.25 = 0.045
- 0.045 落在 (-0.30, +0.30) 之间 → 震荡

又比如：
- EMA微涨但ADX很弱 → 互相抵消 → 震荡
- EMA看多但资金费率极度偏空 → 互相抵消 → 震荡

**重要：不存在"ADX<20=震荡"这种独立门槛。** 震荡是三个因子互相PK后余下的中间地带。

### 牛熊切换有延迟吗？

有的。因为：
1. EMA(50)需要50根K线（约8天）来平滑 → 反应慢
2. 斜率回看20根K线 → 额外延迟
3. 阈值±0.30 → 信号要足够强才切换

所以可能出现：价格已经跌了10%，系统还显示"牛市"（因为EMA还没反应过来）。

## 三、交易信号逻辑

### 三个指标，AND组合

当前策略使用三个技术指标：

| 指标 | 简单解释 | 做多条件 | 做空条件 |
|------|---------|---------|---------|
| EMA双均线 | 快线(15)和慢线(60)的关系 | 快线向上穿过慢线（金叉） | 快线向下穿过慢线（死叉） |
| 成交量突破 | 今天交易量是否异常大 | 量放大 + 价格上涨 | 量放大 + 价格下跌 |
| 斐波那契回调 | 价格是否在关键位置 | 到支撑位反弹 | 到阻力位回落 |

### 开仓条件（必须同时满足才开仓）

```
多头开仓 = EMA金叉 ✓ + 放量上涨 ✓ + FIB支撑位 ✓ + 不在熊市 ✓
空头开仓 = EMA死叉 ✓ + 放量下跌 ✓ + FIB阻力位 ✓ + 不在牛市 ✓
```

三个指标是AND关系，缺一不可。

### 什么时候平仓？

- 价格达到止盈价 → 止盈平仓
- 价格达到止损价 → 止损平仓
- 启动了移动止损 → 跟涨保护
- 回测结束 → 强制平仓
- 爆仓 → 强制平仓

**没有"平仓信号"指标。** 平仓只由价格触发，不由指标触发。

## 四、仓位管理逻辑

### 核心概念：市场状态决定你应该暴露多少风险

```
牛市 → 你敢拿全部资金去交易 → 100%仓位
震荡 → 你只想拿一半试试 → 50%仓位
熊市 → 你只敢拿一点点 → 30%仓位
```

这三个百分比（100% / 50% / 30%）是**可调的**，你可以在界面上修改。

### 两种仓位计算模式

#### 模式A：固定资金比例（Fixed Capital）

**公式**: 保证金 = 总资金 × 市场仓位%

```
10000U账户的例子:
  牛市: 保证金 = 10000 × 100% = 10000U  (3倍杠杆 → 名义仓位30000U)
  震荡: 保证金 = 10000 × 50%  = 5000U   (3倍杠杆 → 名义仓位15000U)
  熊市: 保证金 = 10000 × 30%  = 3000U   (3倍杠杆 → 名义仓位9000U)
```

特点：
- 简单直接，仓位不随价格波动变化
- 不考虑"这笔交易可能亏多少"

#### 模式B：固定风险金额（Fixed Risk）

**公式**:
1. 先算最多能亏多少：`风险预算 = 总资金 × 单笔风险% × 市场仓位%`
2. 再算止损距离：`止损距离 = 开仓价 × 止损%`
3. 最后倒推仓位：`仓位大小 = 风险预算 / 止损距离`

```
10000U账户, 单笔风险1%, 牛市的例子:
  风险预算 = 10000 × 1% × 100% = 100U  (这单最多亏100U)
  止损距离 = 2000U × 5% = 100U         (价格跌100U就止损)
  仓位大小 = 100 / 100 = 1             (开1个单位)
  
震荡市(50%):
  风险预算 = 10000 × 1% × 50% = 50U
  仓位自动缩小一半
```

特点：
- 精确控制每笔交易最多亏多少钱
- 市场不好时自动缩仓
- **有上限保护**：不管公式算出多大仓位，名义仓位不会超过总资金的5倍

## 五、风险控制逻辑

### 五层保护

| 保护层 | 干什么 | 在哪里生效 |
|--------|--------|-----------|
| 连亏锁仓 | 连续亏3笔 → 强制休息2天 | 主循环开头 |
| 单笔止损 | 每笔交易设止损价，跌到就走 | 每根K线检查 |
| 移动止损 | 盈利多了自动上移止损位（保利润） | 每根K线检查 |
| 爆仓保护 | 亏损超过保证金 → 强制平仓 | 平仓时检查 |
| 仓位上限 | 名义仓位不超过总资金的5倍 | 开仓时检查 |

### 连亏锁仓的细节

只算"触发止损"的亏损。盈利平仓（止盈）不会触发计数。

```
亏了 → 计数器+1
      如果计数器≥3 → 锁仓2天，计数器重置
赚了 → 计数器重置为0
```

锁仓期间不开新仓，但已有仓位继续检查止盈止损。

### ATR入场止损

ATR = 平均真实波幅，简单说就是"最近这段时间价格平均波动多少"。

**止损价 = 开仓价 ± ATR × 倍数（默认2倍）**，在入场时一次性设定。

比如ATR=50U，倍数=2：
- 止损距离 = 50 × 2 = 100U
- 做多: 止损价 = 开仓价 - 100U（入场时设定，持仓期间不再按ATR更新）

**重要：ATR止损是入场时一次性定价，不是持仓期动态更新。** 系统只读取这个固定止损价来检查触发。持仓期间唯一的动态止损机制是 **移动止损（trailing_pct）**：当盈利足够多后，止损位会自动向有利方向移动以保护利润。

## 六、止盈止损逻辑

### 两种止盈模式（用户可选）

| 模式 | 含义 | 例子 (10%止盈, 3x杠杆) |
|------|------|------------------------|
| 保证金收益率 | 保证金赚了10%就止盈 | 开仓价2000U，止盈价=2000×(1+10%/3)=2067U |
| 价格百分比 | 价格上涨10%就止盈 | 开仓价2000U，止盈价=2000×(1+10%)=2200U |

### 关键区别

**保证金模式**：杠杆越高，止盈价格越近。

比如同样10%止盈：
- 1倍杠杆：止盈距离 = 10%价格（200U）
- 3倍杠杆：止盈距离 = 3.3%价格（67U）
- 5倍杠杆：止盈距离 = 2%价格（40U）

**价格模式**：止盈距离与杠杆无关，永远是固定的价格百分比。

### 止损同理

止损也支持两种模式，逻辑和止盈一致。

### ATR止损的优先级

如果启用了ATR止损 → ATR止损覆盖保证金/价格止损。

也就是说，设置了"保证金止损5%"，但ATR算出来止损距离更大 → 用ATR的。

## 七、杠杆影响逻辑

### 杠杆不只是"放大收益"

在当前系统中，杠杆同时影响：

1. **止盈止损价格距离**（保证金模式）
   - 高杠杆 = 止盈价更近 = 更容易触发止盈
   
2. **交易频率**
   - 高杠杆 = TP/SL更容易触发 = 交易次数增加

3. **仓位大小**（Fixed Risk模式）
   - 高杠杆 = 止损距离更小 = 仓位公式算出更大仓位
   - 但有仓位上限保护（不超过5倍权益）

4. **回撤幅度**
   - 高杠杆 = 每笔盈亏波动更大

### 历史测试结论

3-4倍杠杆是当前策略的较优区间。

- 1倍杠杆：止盈距离太远（保证金15%需要价格涨15%），太难触发
- 5倍杠杆：止损距离太近（保证金5%需要价格跌1%），容易被噪音扫出去

## 八、当前系统可能风险点

### 1. 牛熊判断的滞后性
EMA(50)+20根回看 → 趋势确认慢。市场快速反转时系统可能反应不及。

### 2. 震荡市频繁切换
EMA斜率在0附近反复 → regime在bull/range/bear间来回跳 → 仓位忽大忽小。

### 3. 没有独立的趋势强度过滤
不像传统系统那样"ADX<20=不交易"。只要三个因子总分不极端，系统就会交易。

### 4. 三个指标AND组合
同时要求EMA金叉+放量+FIB到位 → 条件严格 → 交易频率可能偏低 → 可能错过一些机会。

### 5. Fixed Risk的公式敏感性
止损距离的计算对仓位影响很大。如果止损%设得太小，Fixed Risk会算出超大仓位（但有5倍上限保护）。

### 6. ATR入场止损的双刃剑
波动大时ATR大 → 止损宽 → 单笔亏损可能很大。波动小时ATR小 → 止损窄 → 容易被扫出去。止损价在入场时一次性设定，不随市场波动调整，因此入场后若波动急剧放大，止损保护不会自动放宽。
