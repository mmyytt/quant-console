## 一、关键疑问：止损% = 5 到底指什么？

### 简短回答

取决于你在 UI 上选的**止损模式**：

| 止损模式 | 含义 | 代码依据 |
|----------|------|----------|
| **保证金亏损率 (Margin%)**（默认） | 账户**保证金亏了 5%** 就平仓 | `engine_core.py:585` `self.sl_pct = sl_pct / 100.0` |
| **价格百分比 (Price%)** | 标的价格跌了 5% 就平仓 | 同上，但计算方式不同 |

### 详细说明（4倍杠杆举例）

假设 ETH 价格 $2,000，4x 杠杆，名义仓位 $40,000（占用 $10,000 保证金）：

**保证金%模式（默认）：止损% = 5%**

> 含义：保证金亏 5% → 账户亏 $10,000 × 5% = **$500**

代码如何算止损价（见 `_open()` L1166-1169）：
```
sl_price = 成交价 × (1 - 5% / 4) = $2,000 × 0.9875 = $1,975
```

价格只需要跌 **1.25%**（$25），4x 杠杆放大后保证金亏 5%。此时名义仓位 $40,000 × 1.25% = **$500 亏损**。

**价格%模式：止损% = 5%**

> 含义：标的价格跌 5% → 不管杠杆多少，价格到位就平仓

代码（`_open()` L1160-1162）：
```
sl_price = 成交价 × (1 - 5%) = $2,000 × 0.95 = $1,900
```

4x 杠杆下：价格跌 5% → 保证金亏 5% × 4 = **20%** → **$2,000 亏损**。

### 总结一句话

| 止损模式 | 止损价计算 | 4x 杠杆下价格距离 | 实际亏损金额 |
|----------|-----------|:---:|:---:|
| 保证金% 5% | `price × (1 - 5%/4)` | 1.25% | $500 |
| 价格% 5% | `price × (1 - 5%)` | 5% | $2,000 |

## 二、ATR 动态止损：会覆盖 UI 上的止损%滑块吗？

### 简短回答：**会，ATR 开启后完全覆盖 UI 止损%**

代码在 `_open()` L1171-1181：

```python
# Step 2b: ATR入场止损覆盖
if hasattr(self, '_use_atr_sl') and self._use_atr_sl:
    atr_val = atr_value if (atr_value and atr_value > 0) else fill_price * 0.01
    atr_mult = getattr(self, '_atr_mult', 2.0)
    if side == 'LONG':
        sl_price = fill_price - atr_val * atr_mult   # ← 直接重写 sl_price！
```

**执行顺序**：
1. 先按 UI 止损% 算出 `sl_price`（L1158-1169）
2. 如果勾选了 ATR → **立即覆盖** sl_price = 成交价 - ATR(14) × 倍数
3. 后续用新的 `sl_price` 算 `sl_distance` → 参与仓位计算

**关键特性**：
- ATR 止损在**入场那一刻**一次性定价，持仓期间不再随 ATR 更新
- 持仓期间的动态止损由另一个独立机制 `trailing_pct`（移动止损）负责
- ATR(14) 值来自每根 K 线预计算的数据，不是固定常量

## 三、完整数据流水线：从信号触发到下单

### 管道总览

```
信号触发 → 轮动选币 → 读环境系数 → 算止损价 → 算仓位 → 风控校验 → 算止盈价 → 下单
```

### Step-by-step 详解

---

#### Step 0：收到信号（`engine_core.py` 主循环 L644-788）

引擎每一根 4H K 线前进，检测 `df['signal']` 列：
- `signal = 1` → 做多信号
- `signal = -1` → 做空信号
- `signal = 0` → 无信号

---

#### Step 1：轮动选币（`_try_rotate_entry()` L886-951）

如果有多个币种同时出信号，只选**评分最高**的那个：

```
candidates = 遍历所有币种
  → 检查冷却期（刚平仓的跳过）
  → 读取: signal, regime(牛/震/熊), score, bear_ratio
  → 过滤: 空头比例超限的跳过
  → 选出 score 最高的
```

---

#### Step 2：读参数（`_try_rotate_entry()` L936-937 + `run()` L662-680）

每次开仓前，从用户 UI 配置中读取：

```python
alloc = self._init_alloc_pct / 100.0    # 单笔建仓比例% → 小数（来自UI: pyr_init_pct）
```

`run()` 函数在回测开始时一次性从 `strategy.selected` 读取：
- `_pos_mode` → `"fixed_capital"` 或 `"fixed_risk"`
- `_risk_per_trade` → 除以 100 转为小数（如 2.0 → 0.02）
- `_bull_alloc / _range_alloc / _bear_alloc` → 除以 100 转为小数（如 100.0 → 1.0）
- `_init_alloc_pct` → 原始值，在 `_try_rotate_entry` 中 /100

**`alloc`（单笔建仓比例%）是一个"总阀门"**——它不是替代 regime 乘数，而是和 regime 乘数**相乘**，共同作用于仓位公式。

---

#### Step 3：开仓入口（`_open()` L1116-1283）

核心公式在 `_open()` 方法中，分 5 步：

---

##### Step 3.1：获取环境乘数（L1144-1156）

根据当前 K 线的市场状态，查表取乘数：

```python
if regime == 'bull':   regime_mult = self.bull_alloc   # 默认 1.0（100%）
elif regime == 'bear':  regime_mult = self.bear_alloc  # 默认 0.3（30%）
else:                  regime_mult = self.range_alloc  # 默认 0.5（50%）
```

> **如果用户设某状态乘数为 0 → 直接 return，不开仓**

---

##### Step 3.2：算止损价（L1158-1183）

**仅在 Fixed Capital 和 Fixed Risk 模式下执行**（Dynamic Stop 跳过后算）：

```
margin_pct 模式:
  LONG:  sl_price = 成交价 × (1 - 止损% / 杠杆)
  SHORT: sl_price = 成交价 × (1 + 止损% / 杠杆)

price_pct 模式:
  LONG:  sl_price = 成交价 × (1 - 止损%)
  SHORT: sl_price = 成交价 × (1 + 止损%)
```

如果勾选了 ATR 动态止损 → **覆盖** sl_price（见第二部分）。

然后：`sl_distance = abs(成交价 - 止损价)` — 这是每单位的亏损距离（美元）。

---

##### Step 3.3：算仓位（L1185-1208） —— 这里是核心分歧点

---

### 模式 A：固定资金比例 (Fixed Capital %)

**正向计算**：我打算投入多少保证金 → 得出名义仓位

```
margin  = 账户权益 × 环境乘数 × 建仓比例
        = equity × regime_mult × init_alloc

notional = margin × 杠杆
         = equity × regime_mult × init_alloc × lev
```

**举例（牛市，4x 杠杆，建仓 30%）**：
```
margin  = $10,000 × 1.0 × 0.3 = $3,000
notional = $3,000 × 4 = $12,000
```

### 模式 B：固定风险比例 (Fixed Risk %)

**逆向计算**：我能亏多少钱 → 根据止损距离倒推能开多少仓位

```
risk_budget    = 账户权益 × 单笔风险% × 环境乘数 × 建仓比例
               = equity × risk_pct × regime_mult × init_alloc

position_units = risk_budget ÷ sl_distance          ← 能买几个币
notional       = position_units × 成交价            ← 名义价值
margin         = notional ÷ 杠杆                    ← 占用保证金
```

**等价简化公式**（margin_pct 止损模式）：
```
margin = equity × risk_pct × regime_mult × init_alloc ÷ sl_pct
       = equity × (risk% / sl%) × regime_mult × init_alloc
```

**举例（牛市，4x 杠杆，建仓 30%，risk=2%，SL=5% 保证金）**：
```
risk_budget    = $10,000 × 0.02 × 1.0 × 0.3 = $60
sl_distance    = $2,000 × 0.05 / 4 = $25/unit
position_units = $60 / $25 = 2.4 ETH
notional       = 2.4 × $2,000 = $4,800
margin         = $4,800 / 4 = $1,200
```

> **关键洞察**：Fixed Risk 的实际保证金 = Fixed Capital 保证金 × (risk% / sl%)
> 
> risk%=2%, sl%=5% → Fixed Risk 仓位 = Fixed Capital 的 40%
> 
> risk%=5%, sl%=5% → **一模一样！**（risk 和 sl 互相抵消）

---

#### 环境乘数（牛/震/熊%）在哪一步生效？

**两个模式都会乘**，而且乘在**同一个位置**——都是 `regime_mult` 这个变量：

| 模式 | 公式 | 环境乘数的作用 |
|------|------|------|
| Fixed Capital | `margin = equity × [regime_mult] × init_alloc` | 直接缩放保证金 |
| Fixed Risk | `risk_budget = equity × risk_pct × [regime_mult] × init_alloc` | 缩放风险预算 |

- 牛市 ×100% = 不变
- 震荡 ×50% = 仓位减半
- 熊市 ×30% = 仓位缩到 30%

两个模式下效果一致：熊市 30% → Fixed Capital 只投 30% 保证金，Fixed Risk 只用 30% 风险预算。

---

##### Step 3.4：硬风控校验（L1226-1240）

**4a. 保证金不足保护**：
```python
if margin > self.equity:
    margin = self.equity    # ← 强行封顶：最多用全部权益
    notional = margin × lev
```

**举例**：risk=10%、init_alloc=100% → 理论保证金 $20,000（超过 $10,000 权益），实际封顶到 $10,000。

**4b. 累计名义仓位上限**：
```python
max_notional = equity × 5.0        # 默认 5 倍权益
total_notional = 已有持仓名义 + 本次新增名义
if total_notional > max_notional:
    notional = max(0, max_notional - 已有持仓名义)  # 只缩减本次新增部分
    margin = notional / lev
```

---

##### Step 3.5：算止盈价（L1242-1252）

止盈价格**不参与仓位公式**，仅用于持仓期间的触发检查：
```
margin_pct 模式: tp_price = 成交价 × (1 + 止盈% / 杠杆)
price_pct 模式: tp_price = 成交价 × (1 + 止盈%)
```

---

#### Step 4：持仓期间检查（`_check_positions()` L793-881）

每根 K 线检查：
1. **TP 触及**？→ 平仓止盈
2. **SL 触及**？→ 平仓止损
3. **TP 和 SL 同时触及**？→ 保守原则，取 SL（最坏情况）
4. **移动止损**？→ 从最高价回撤超过 `trailing_pct`% 就平仓
5. **爆仓**？→ 浮亏超过保证金或触及强平价

平仓后：
- 触发冷却期（默认 2 根 K 线不能重开）
- 任意亏损（`margin_pnl < 0`）计入连亏计数器
- 连亏 ≥ 3 笔 → 锁仓 48 天（4H K 线 × 288 根）

## 四、代码一致性排查结果

### ✅ 一致的部分

| 检查项 | 结果 |
|--------|------|
| UI `_pos_mode` → `selected` → `engine.run()` 读取 | 一致，"fixed_risk"/"fixed_capital" 字符串匹配 |
| UI `bull_a/range_a/bear_a` 百分比 → 引擎 /100 转乘数 | 一致 |
| UI `risk_per_trade` 百分比 → 引擎 /100 转小数 | 一致 |
| ATR 覆盖止损价的计算逻辑 | 一致，入场时一次性定价 |
| 硬风控封顶保护 | 一致，margin > equity 时自动截断 |

### ⚠️ 需要注意的地方

| 问题 | 说明 |
|------|------|
| **risk% = sl% 时模式收敛** | 当 `risk_per_trade ≈ sl_pct` 时，Fixed Risk 仓位公式退化到与 Fixed Capital 完全相同。这不是 Bug，而是数学性质。UI 已添加警告提示。 |
| **保证金%止损模式下 SL 距离随杠杆变化** | SL=5% 保证金 + 4x 杠杆 → 实际价格只需跌 1.25%。如果你想要"价格跌 5% 就止损"，请切换到**价格百分比 (Price%)** 模式。 |
| **`except: pass` 已修复** | 之前 `run()` 中参数读取用裸 `except: pass`，现已改为打印 `traceback` 的具体异常处理。 |

## 五、速查公式卡

```
═══════════════════════════════════════════════════════════
  Fixed Capital（固定资金比例）
  
  margin   = equity × regime_mult × init_alloc_pct
  notional = margin × leverage
  sl_price = fill_price × (1 - sl_pct / leverage)  [保证金%]
           = fill_price × (1 - sl_pct)              [价格%]
  
  特点: 仓位由"我愿意投多少保证金"决定
═══════════════════════════════════════════════════════════
  Fixed Risk（固定风险比例）
  
  risk_budget = equity × risk_pct × regime_mult × init_alloc_pct
  sl_distance = abs(fill_price - sl_price)
  units       = risk_budget / sl_distance
  notional    = units × fill_price
  margin      = notional / leverage
  
  简化: margin = equity × (risk%/sl%) × regime_mult × init_alloc_pct
  
  特点: 仓位由"我最多亏多少钱"倒推
═══════════════════════════════════════════════════════════
  Dynamic Stop（动态止损倒推）
  
  margin   = equity × regime_mult × init_alloc_pct  [同Fixed Capital]
  notional = margin × leverage
  dyn_sl%  = risk_budget / notional                  [价格百分比]
  sl_price = fill_price × (1 - dyn_sl%)
  
  特点: 仓位吃满 + 止损动态收紧
═══════════════════════════════════════════════════════════
```

### 变量速查

| 变量 | 来源 | 默认值 | 含义 |
|------|------|:---:|------|
| `equity` | 引擎内部 | $10,000 | 当前账户权益 |
| `leverage` | UI 杠杆 | 3x | 合约杠杆倍数 |
| `regime_mult` | UI 牛/震/熊% | 1.0/0.5/0.3 | 市场状态风险乘数 |
| `init_alloc_pct` | UI 单笔建仓比例% | 30% | 每笔建仓占总资金的比例 |
| `risk_pct` | UI 单笔风险占比% | 1% | 每笔最大亏损占权益的%（仅 Fixed Risk/Dynamic Stop） |
| `sl_pct` | UI 止损% | 5% | 止损线（保证金% 或 价格%，取决于 sl_mode） |
| `sl_distance` | 引擎计算 | — | `abs(成交价 - 止损价)`，单位：美元/币 |
| `max_notional_pct` | 引擎常量 | 5.0 | 最大名义仓位 = equity × 5 |
